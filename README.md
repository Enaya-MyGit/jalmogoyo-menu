# Jalmogoyo – menu (FR · EN · DE · 한국어)

Multilingual tablet menu for the Korean restaurant Jalmogoyo, Mulhouse.

**Live version:** https://enaya-mygit.github.io/jalmogoyo-menu/

On a Samsung tablet, open the link in Chrome or Samsung Internet, then use ⋮ → **Add to Home screen / Install app**. After the first visit the menu also works offline.

The menu content (prices, dishes, translations) is in `js/menu-data.js`.
